## My setup link doesn't work

The page says **This link has expired. Ask for a new one.** If you already set up your account with it, just sign in instead. Otherwise, see [Set up your account](/start/set-up-your-account/) for the fix.

## I forgot my password

On the sign-in page, choose **Forgot your password?**, type your email and choose **Send the link**, then follow the email. If you set up a passkey, you can also choose **Sign in with a passkey** instead. See [Set up your account](/start/set-up-your-account/) for how the reset link works.

## It keeps saying "Email or password is incorrect"

Check the email address and password for typos first. If they're right, the account may be temporarily locked — the page keeps showing the same message while it's locked. See [Set up your account](/start/set-up-your-account/) for how long, or reset your password.

## The connector won't connect

Check that the URL is `https://app.telekin.ai/mcp`, with `/mcp` at the end. If you use a key, also check that the header value starts with `Bearer ` (with a space). If you meant to sign in in the browser, check that there's no `Authorization` header left in the app's settings: some apps skip the sign-in when one is set.

## The sign-in page never opens

Some apps sign in only when you ask: in Claude Code, run `/mcp` and choose **Authenticate**; in Codex CLI, run `codex mcp login telekin`; in Gemini CLI, run `/mcp auth telekin`. On a machine with no browser, such as over SSH, copy the address the app prints into a browser on another device if the app allows it, or use a key ([Make a key](/how-to/guides/make-a-key/)).

## The sign-in stopped partway

Signing in and approving must finish within 10 minutes of Telekin's page opening. If the page says the request has expired or is not valid, start again from the app: add the connector or choose connect again, and the page opens afresh.

## A memory isn't in the list

When you approve an app or make a key, Telekin offers only the memories your account reaches: your teams' memories, at the level each team allows, plus any memory shared with you. If a memory is missing, or only **read** is offered, your account doesn't reach it at that level. The **Account** page lists what it reaches under **Your ceiling**. Ask the team's owner, or whoever shared the memory with you, for access. If the approval page says you have no catalogs to share yet, your account reaches none so far.

## Making a key is refused

The message names the limit: more access than your account has, more keys than you're allowed, or an expiry past the longest allowed. Change that choice, or revoke a key you no longer use, and try again. See [Make a key](/how-to/guides/make-a-key/).

## A connection that worked has stopped

In your Telekin console, check **My grants** (for an app that signed in in the browser) or **My keys** (for an app that uses a key).

- A key may have **expired** or been **revoked**. Tick **Show revoked and expired keys** to see it. Make a new key and put it in the tool in place of the old one.
- A connection on **My grants** that shows as revoked, or is gone, was disconnected: by you, or automatically after 30 days unused. Sign in again from the app (for example `/mcp`, then **Authenticate**, in Claude Code), or remove the connector and add it again, and approve it.
- If your account's access was lowered, the key or connection reaches less than before. See [A memory isn't in the list](#a-memory-isnt-in-the-list).

## The AI says it has no tools

In Claude, make sure the Telekin connector is switched on in this chat: click **+**, then **Connectors**. In other apps, check the app's MCP settings for Telekin and restart the app.

## The AI has the tools but never uses them

It needs a nudge. Add the custom instructions for your app from [Get your AI to use Telekin without being asked](/how-to/guides/use-without-asking/#text-for-your-app). In the Claude apps, this matters most: they don't pass on Telekin's own instructions, and Claude doesn't think of Telekin until something tells it to.

If it saves to its own built-in memory instead of Telekin, the instructions fix that too: they tell it to use Telekin in place of the app's memory.

## Free plan: can't add a second connector

The free plan allows only one custom connector — see [Connect Claude](/how-to/connect/claude/). Remove the one you don't need, or use a different app for the second connection. To change a connector's settings later, remove it and add it again.

## A header seems to be ignored

Most people don't need a catalog header at all, because Telekin already uses your default catalog, or your only one. If you use one, a misspelled name is silently ignored, with no error — check the spelling first. The full header spec is in [Connection settings](/reference/connection-settings/).

## Anything else

<a href={CONTACT_URL}>Send us a message</a> with a screenshot, or use [Send feedback](/feedback/). Leave any key out of the screenshot.

If the error shows a **trace id** (a long string of letters and numbers, shown after "Trace id:" in the console, or quoted by your AI when a Telekin tool fails with an internal error), include it. It's what lets us find the exact request that failed. Developers can also find it in the `X-Trace-Id` header on Telekin's API and console responses (not on static files such as scripts and images).
