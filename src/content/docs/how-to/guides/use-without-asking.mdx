Connecting Telekin gives your AI the tools to use it. It doesn't always think to. This page makes it check Telekin by itself, and save to it.

## What the instructions say

Give your AI three instructions, in its custom instructions (or rules, or preferences: each app has its own name for them):

1. **Telekin is its memory.** If the app has a memory of its own, say to use Telekin instead. Otherwise, when you say "remember this", it may save to the app's memory and not to Telekin.
2. **Search Telekin first,** before answering from what it already knows or searching the web. Some apps don't pass on the instructions Telekin sends when a chat starts. In those apps, the AI should also call Telekin's `guide` tool before its first search, to read them.
3. **Save by default, then say what was saved.** The catalog only improves when it grows. If the AI only saves what it judges "worth remembering", it holds back. Saving new things and fixing outdated ones without asking works better. It then tells you what it saved, so you can say "take that out", and every publish can be undone (see [Review, undo and export](/how-to/guides/review-undo-export/)).

Don't tell it to search only "when I mention a project, system or person". The AI reads a list like that as the only times to look.

## Text for your app

Copy the text for your app. Where it goes moves around between app versions. If you can't find the place, search the app's settings for "instructions", "rules" or "preferences".

### Claude apps

For Claude on the web, Claude Desktop and the Claude mobile apps. They don't pass on Telekin's own instructions, and they keep Telekin's tools hidden until Claude decides it needs one. Without this text, Claude often doesn't think of Telekin at all.

**Where it goes:** Settings, then **Your Claude**, then **Instructions** (older versions call it your personal preferences, under your profile). It applies to every chat, on every device you sign in on.

```text
* My Telekin connector is my knowledge catalog and my memory. Use it instead of Claude's built-in memory.
* Before answering from what you know or searching the web, search Telekin. Before the first search in a conversation, call its `guide` tool.
* The catalog only improves when it grows. Save new things and fix outdated ones by default, without asking, and then tell me what you saved.
```

If you named the connector something other than `Telekin`, use that name.

### ChatGPT

ChatGPT passes on Telekin's instructions, so it doesn't need the `guide` step.

**Where it goes:** on the web and in the desktop app, Settings, then **Personalization**, then **Custom instructions** (turn on **Enable customization** if it's off). In the mobile app, Settings, then **Customize ChatGPT**.

```text
* Telekin is my knowledge catalog and my memory. Use it instead of ChatGPT's memory.
* Before answering from what you know or searching the web, search Telekin.
* The catalog only improves when it grows. Save new things and fix outdated ones by default, without asking, and then tell me what you saved.
```

### Claude Code

Claude Code passes on Telekin's instructions, so it doesn't need the `guide` step. For the full setup, with a startup reminder of which catalog is yours, follow [Connect Claude Code, enhanced](/how-to/connect/claude-code-enhanced/) instead.

**Where it goes:** the end of `~/.claude/CLAUDE.md`, which Claude Code reads at the start of every session (create it if it doesn't exist).

```text
* The telekin MCP server is my knowledge catalog and my memory. Use it as your primary memory, ahead of Claude Code's own memory files.
* Before working on anything that might be in Telekin, search it.
* The catalog only improves when it grows. Save new things and fix outdated ones by default, without asking, and then tell me what you saved.
```

### Any other app

Put this wherever the app keeps instructions that apply to every chat. If the app has a memory of its own, add "Use it instead of" and the name of that memory to the first line. The `guide` step is harmless in an app that already passes on Telekin's instructions; it just costs one extra call.

```text
* The telekin MCP server is my knowledge catalog and my memory.
* Before answering from what you know or searching the web, search Telekin. Before the first search in a conversation, call its `guide` tool.
* The catalog only improves when it grows. Save new things and fix outdated ones by default, without asking, and then tell me what you saved.
```

If you gave the server another name when you connected it, use that name in place of `telekin`.

## Habits that help

- **Name the project or system in your question.** "Why is the billing service slow?" gives your AI something to search for. "Why is it slow?" doesn't.
- **Say "check Telekin" when it misses.** If it answers as if it knows nothing, ask it to look. Then it can use what it finds for the rest of the chat.
- **Start a fresh chat when a long one drifts.** Long chats can lose track of their instructions. A new chat starts clean and searches Telekin again.

If your AI still never touches Telekin, see [Troubleshoot](/how-to/guides/troubleshoot/).
