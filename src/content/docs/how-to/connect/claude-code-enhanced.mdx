You'll need: your Telekin account ([Set up your account](/start/set-up-your-account/)), your catalog name (for example `t01`, listed under **Your ceiling** on your console's **Account** page) and `python3`.

<Waitlist />

This setup makes Claude Code check Telekin at the start of every session, use what it finds without being asked, and write back what it learns. It has three parts:

1. **The connection** to the server.
2. **Instructions in your global `CLAUDE.md`** (a file Claude Code reads at the start of every session): how Claude should use Telekin. This part matters most.
3. **A SessionStart hook**: a tiny script that reminds Claude, at the start of every session (and again after `/clear` and compaction), which catalog is yours.

Allow about 10 minutes.

## 1. Connect the server

Follow [Connect Claude Code](/how-to/connect/claude-code/). Keep the name `telekin`, because the instructions below refer to the tools as `mcp__telekin__*`. If you added it under another name (older versions of this page used `okf-mcp`), use that name in place of `telekin` below.

## 2. Add the instructions to your global CLAUDE.md

Open `~/.claude/CLAUDE.md` (create it if it doesn't exist) and add the block below to the end. Replace `<catalog>` with your catalog name and `<you>` with a short handle for yourself (for example your first name in lowercase).

```markdown
# Telekin

I keep a long-term memory of my world (projects, systems, people,
decisions and my preferences) in Telekin, on the telekin MCP server
(`mcp__telekin__*` tools), as catalog `<catalog>`. A SessionStart hook
reminds you of it at the start of every session.

## Reading

- Before working on anything that might be in Telekin, check it first:
  `search`, then `get_concept` on the best hits. Do this without being
  asked, and use what you find openly: say what Telekin told you and build
  on it, instead of asking me to repeat it.
- Check a hit's size (`lines`, `chars`) before reading it. To add to a
  concept, `search` for the spot and `edit_document` it; don't read the
  whole concept first.

## Writing

- To write, call `open_changeset` once and pass its handle as `changeset`
  to every edit and to `publish`. Nothing is saved until `publish`.
- When we establish something worth remembering (how something works, a
  fix, a decision, a preference), add or update the matching concept:
  `create_concept` for new ones (with an `index_summary`), and a `log`
  entry describing the change.
- Write with the server's tools (`create_concept`, `edit_document`,
  `replace_body`, `set_frontmatter`). Never rebuild whole files, and never
  type timestamps; the server writes them.
- Pass `by: "claude-code/<your model id>"` to `create_concept`, `stamp`,
  `review` and `split_concept`, so Telekin records that Claude Code wrote it.
- After updating, `publish` with a clear message. I can undo anything with
  `history` and `revert`.
- Never write secrets (passwords, keys, tokens), or anything my employer
  considers confidential.

## Memory

- Telekin is your primary long-term memory. Record things there first;
  you may also keep them in Claude Code's own memory, but never only
  there.
- Facts about me and how I like to work go in `/people/<you>.md`.
- If the Telekin tools are unavailable, tell me.
```

## 3. Install the SessionStart hook

Save this as `~/.claude/hooks/telekin-session.py`. Set `CATALOG` to your catalog name.

```python
#!/usr/bin/env python3
"""SessionStart hook: tell Claude your knowledge catalog exists and how to use it."""
import json
import sys

CATALOG = "t01"     # your catalog's name (see your Account page)
SERVER = "telekin"  # the name you used in `claude mcp add`


def main():
    try:
        session = json.load(sys.stdin).get("session_id", "")
    except Exception:
        session = ""
    context = (
        f"Knowledge catalog for this session: catalog `{CATALOG}` on the {SERVER} MCP "
        f"server. It holds the user's long-term context: their systems, projects, people, "
        f"decisions and preferences. Read it with the `mcp__{SERVER}__*` tools (search, "
        f"get_concept) and write it through a changeset (open_changeset, then pass its "
        f"handle to every edit and to publish). Pass `catalog: \"{CATALOG}\"` when a tool "
        f"takes one. The catalog instructions in CLAUDE.md apply. Session id: {session}."
    )
    print(json.dumps({"hookSpecificOutput": {
        "hookEventName": "SessionStart", "additionalContext": context}}))


if __name__ == "__main__":
    try:
        main()
    except Exception:
        pass  # never break a session over a reminder
```

Make it executable and test it:

```bash
chmod +x ~/.claude/hooks/telekin-session.py
echo '{"session_id":"test"}' | ~/.claude/hooks/telekin-session.py
```

It should print one line of JSON that starts with `{"hookSpecificOutput"`.

Now register it in `~/.claude/settings.json`.

**If the file doesn't exist, or has no `"hooks"` key yet**, add this at the top level:

```json
{
  "hooks": {
    "SessionStart": [
      {
        "hooks": [
          { "type": "command", "command": "~/.claude/hooks/telekin-session.py", "timeout": 10 }
        ]
      }
    ]
  }
}
```

**If you already have hooks**, add only the inner `{ "hooks": [ ... ] }` object to your existing `"SessionStart"` list (create the list if needed). Don't replace your other hooks.

Or let `jq` merge it safely (it backs up your settings first):

```bash
f=~/.claude/settings.json; [ -f "$f" ] || echo '{}' > "$f"; cp "$f" "$f.bak"
jq '.hooks.SessionStart += [{"hooks":[{"type":"command","command":"~/.claude/hooks/telekin-session.py","timeout":10}]}]' \
  "$f.bak" > "$f"
```

## 4. Check it works

<Steps>

1. Start a new `claude` session in any directory.
2. Ask: **"Which knowledge catalog applies to this session?"** Claude should name your catalog without searching for it. If it doesn't, check `/hooks` to see whether the SessionStart hook is listed.
3. Ask: **"What do you know about me?"** It should search Telekin. On an empty memory it will say there's nothing yet, which is your cue to try [Your first 15 minutes](/start/first-15-minutes/) or [fill Telekin from documents](/start/from-your-documents/).

</Steps>

## Undo it

- `claude mcp logout telekin`, then `claude mcp remove telekin --scope user`
- Delete the "Telekin" block from `~/.claude/CLAUDE.md`.
- Remove the SessionStart entry from `~/.claude/settings.json`, and delete `~/.claude/hooks/telekin-session.py`.
