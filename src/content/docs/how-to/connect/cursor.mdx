You'll need: Cursor installed on this computer, and your Telekin account ([Set up your account](/start/set-up-your-account/)). If you add the server by hand with a key, you'll also need your Telekin address with `/mcp` at the end (the `<server URL>` below) and a key you make for Cursor ([Make a key](/how-to/guides/make-a-key/)).

## Add it with one click

The button below opens Cursor and offers to install Telekin. Cursor then signs in in your browser with your Telekin account, so there's no key to copy or paste.

<LinkButton href="cursor://anysphere.cursor-deeplink/mcp/install?name=telekin&config=eyJ1cmwiOiJodHRwczovL2FwcC50ZWxla2luLmFpL21jcCJ9" icon="external">Add Telekin to Cursor</LinkButton>

<Steps>

1. Click **Add Telekin to Cursor**. If your browser asks whether to open Cursor, allow it.
2. Cursor shows the server it's about to add, named `telekin`. Confirm the install.
3. Cursor opens Telekin's page in your browser. If you're not signed in, sign in with your Telekin account first.
4. The page, **Allow access?**, names the app that's connecting and says what **Approve** gives it. With one memory (Telekin's screens call memories catalogs), that's **write** access to it, as the default catalog, so Cursor can save what it learns. Choose **Approve**. With more than one memory, the choices start open under **Advanced Options**: tick each memory Cursor may use, choose **read** or **write** for each, pick a **Default catalog** (the memory it uses when it doesn't name one), then **Approve**. (**Deny** connects nothing.)
5. Go back to Cursor. `telekin` should show as connected in its MCP settings, with its tools listed.

</Steps>

If the button does nothing, Cursor may not be installed, or your browser may have blocked the link. You can also paste this link into your browser's address bar:

```text
cursor://anysphere.cursor-deeplink/mcp/install?name=telekin&config=eyJ1cmwiOiJodHRwczovL2FwcC50ZWxla2luLmFpL21jcCJ9
```

The link only tells Cursor the server's name and address, `https://app.telekin.ai/mcp`. It carries no key or account details. If the sign-in page expires before you finish, see [Troubleshoot](/how-to/guides/troubleshoot/).

## Add it by hand with a key

If you'd rather not sign in in the browser, or you want Telekin in a single project only, add the server to an `mcp.json` file yourself. There are two places for it:

- `~/.cursor/mcp.json` is the **global** file: the server is available in every project.
- `.cursor/mcp.json` inside a project is the **per-project** file: the server is available only there.

<Steps>

1. Create or edit one of those files so it contains this, with your own server URL and key. If the file already has other servers, add only the `"telekin"` entry inside `mcpServers`.

   ```json
   {
     "mcpServers": {
       "telekin": {
         "url": "<server URL>",
         "headers": {
           "Authorization": "Bearer <your key>"
         }
       }
     }
   }
   ```

2. Restart Cursor.
3. Open **Settings, then MCP**. `telekin` should show as connected, with its tools listed.

</Steps>

To sign in in the browser instead of using a key, leave out the `headers` section.

Menu names move around, so if you can't find the MCP page, search Cursor's settings for "MCP".

## Check it works

In a Cursor chat, ask: **"What tools do you have from Telekin?"** You should see a list. Then ask **"What do you know about me?"**; on an empty memory it will say there's nothing yet.

If it won't connect, check that the URL ends in `/mcp`. If you use a key, check that the header value starts with `Bearer ` (with a space). If signing in or approving doesn't work, see [Troubleshoot](/how-to/guides/troubleshoot/).

## Undo it

Remove `telekin` from Cursor's MCP settings, or delete the `"telekin"` entry from the `mcp.json` file you edited, and restart Cursor. If you signed in in the browser, also disconnect it from Telekin's side: in your Telekin console, open **My grants**, choose the Cursor connection, then **Revoke**.
