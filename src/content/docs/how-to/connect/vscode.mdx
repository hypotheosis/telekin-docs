You'll need: your Telekin account ([Set up your account](/start/set-up-your-account/)).

VS Code signs in in your browser with your Telekin account, so there's no key to copy or paste.

## Add the server

<Steps>

1. Open the Command Palette and run **MCP: Add Server**. Choose **HTTP**, enter `https://app.telekin.ai/mcp` as the URL, and `telekin` as the server ID. Choose whether it's for this workspace or for every project.

   Or add it to an MCP config file yourself. The server entry needs only the address:

   ```json
   {
     "servers": {
       "telekin": {
         "type": "http",
         "url": "https://app.telekin.ai/mcp"
       }
     }
   }
   ```

2. When the server starts, VS Code asks to sign in. Allow it, and your browser opens Telekin's page. If nothing asks, look for an **Authenticate** action on the server in the MCP server list.

3. If you're not signed in to Telekin, sign in. The page, **Allow access?**, names VS Code and says what **Approve** gives it: with one memory (Telekin's screens call memories catalogs), that's **write** access to it, as the default. Choose **Approve**. With more than one memory, choose under **Advanced Options** first. (**Deny** connects nothing.)

4. Back in VS Code, `telekin` should show as running, with its tools listed.

</Steps>

VS Code's docs now describe more than one place and format for MCP servers, and newer Copilot setups read a `.mcp.json` file with an `mcpServers` list. Whichever file you use, the entry is just Telekin's address; leave out any `headers`.

Organization settings can restrict MCP access in VS Code. If you can't add the server, ask whoever manages your Copilot.

## Use a key instead

If you'd rather not sign in in the browser, make a key ([Make a key](/how-to/guides/make-a-key/)) and let VS Code ask for it once and store it securely:

```json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "telekin-key",
      "description": "Telekin key",
      "password": true
    }
  ],
  "servers": {
    "telekin": {
      "type": "http",
      "url": "https://app.telekin.ai/mcp",
      "headers": {
        "Authorization": "Bearer ${input:telekin-key}"
      }
    }
  }
}
```

When VS Code asks for `telekin-key`, enter the key alone, without the word `Bearer`: the file already adds it.

## Check it works

Open Copilot chat in agent mode and ask: **"What tools do you have from Telekin?"** You should see a list. Then ask **"What do you know about me?"**; on an empty memory it will say there's nothing yet. VS Code asks you to approve each tool call, so approve the request when it appears.

If it won't connect, check that the URL ends in `/mcp`.

## Make it use Telekin on its own

To make Copilot check Telekin by itself, and save to it instead of Copilot Memory, add the [text for VS Code](/how-to/guides/use-without-asking/#vs-code-github-copilot) to a user instructions file.

## Undo it

Delete the `"telekin"` entry from the MCP config file, or remove the server from VS Code's MCP server list. To disconnect it from Telekin's side, open **My grants** in your Telekin console, choose the VS Code connection, then **Revoke**. If you used a key, revoke it on **My keys**.
