Every app that connects to Telekin needs the same few settings, whatever it calls them. The server URL is `https://app.telekin.ai/mcp`. Developer tools send a key you make on **My keys** ([Make a key](/how-to/guides/make-a-key/)); Claude on the web and desktop, and ChatGPT, sign in in your browser with your Telekin account instead. Telekin accepts both ways at the same URL.

| Setting | Value | Required |
|---|---|---|
| URL | `<server URL>`, which ends in `/mcp` | Yes |
| Transport | Streamable HTTP (some apps just call it "HTTP") | Yes |
| `Authorization` header | `Bearer <your key>`: the word `Bearer`, a space, then your key | Yes |
| `X-OKF-Catalogs` header | One or more catalog names, separated by commas, such as `t01`. Plural: `Catalogs`, not `Catalog` | No. Usually unnecessary |
| `?catalogs=` query parameter | The same catalog names, added to the end of the URL, such as `<server URL>?catalogs=t01` | No. An alternative to the header |

## OAuth sign-in

Claude on the web and desktop, and ChatGPT, sign in with OAuth: you sign in with your Telekin account in your browser and approve the connection, instead of sending a key in a header.

| Setting | Value |
|---|---|
| URL | `<server URL>`, which ends in `/mcp` (the same as with a key) |
| Authentication | OAuth. Leave any client ID and client secret empty |
| Signing in | Your Telekin account (email and password, or a passkey), on Telekin's page in your browser |
| Approving | On **Allow access?**, tick the catalogs the app may use, choose `read` or `write` for each, pick a default catalog, then **Approve** |
| Sign-in time limit | Finish within 10 minutes of the page opening |
| Revoking | **My grants** in your Telekin console |

Each app you connect is approved separately, and reconnecting after a disconnect means approving again. A connected app stays connected as long as it's used regularly. The `Authorization` header above applies to keys; with OAuth, the catalogs you approve decide what the app reaches.

## Which catalog Telekin uses

A catalog is one collection of your notes. Most people have exactly one, and the key or connection they made already points at it as its default catalog, so they never set a catalog at all.

If you can reach more than one, Telekin picks in this order and stops at the first that names a catalog:

1. The `X-OKF-Catalogs` header.
2. The `?catalogs=` query parameter.
3. The default catalog you chose when you made your key or approved the connection.

A misspelled header name is silently ignored, so if the wrong catalog is used, check the spelling first. Catalog names are case-sensitive: `T01` does not match `t01`.

Setup steps for each app are under [Connect your AI](/how-to/connect/). If something won't connect, see [Troubleshoot](/how-to/guides/troubleshoot/).
